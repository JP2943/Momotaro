## 2. 地図と住民の位置

```
            [H 崖道（困難）] ──扉── [C 合流点・ボス前]
               │扉                     │
   北の門（閉）・立て札                │
[A 拠点] ──────スライド────── [B 街道（標準）] ──スライド──┘
```

| 場所 | あるもの |
|---|---|
| **A（拠点）** | 南西に開始地点のお地蔵様。その北東に **案内の老人**（左）と **村の娘**（右）が立っています（頭の上に名前）。北に閉じた門と立て札「北の門（崖道）」、門の奥に「崖道へ（扉）」。東の通路から B へ |
| **B（街道・標準ルート）** | 平らな道。北と南に鬼の遭遇戦。東の端から C へ |
| **H（崖道・困難ルート）** | 岩の壁と待ち伏せの鬼 2 体。西の行き止まりの岩陰に**巻物**。東の「合流点へ（扉）」で C へ |
| **C（合流点）** | お地蔵様と仮章ボス（精鋭の鬼）の遭遇戦。B 側と H 側の 2 つの入口がある |

## 3. 操作（調べる以外は会話用）

| したいこと | キーボード | パッド |
|---|---|---|
| 話しかける・調べる | `E` | A（×） |
| 次へ・決定 | `E`／`Enter` | A（×） |
| 選択肢を選ぶ | `↑`／`↓`（またはマウスでクリック） | 十字キー |
| 閉じる（今は受けない） | `Esc` | B（○） |
| 依頼一覧 | `Esc` でメニュー →「依頼一覧」 | Start → 依頼一覧 |

会話中はゲームが止まります（主人公・犬丸・敵・矢・反撃強化の残り時間）。閉じると元に戻ります。会話や依頼の報告は休息ではありません（回復しない・敵は戻らない）。

## 4. 試してほしいこと

1. **道の話を聞く**：案内の老人に話す。最初は門の話（「北の門を開けてもらう」で門が開く）。途中で閉じると何も起きない。
2. **依頼を受ける**：村の娘に話す →「依頼「…」の話を聞く」→ 目的と報酬（徳 30）→「依頼を受ける」／「今は受けない」。断っても後で受けられる。
3. **条件を満たす**：①合流点（C）へ行く ②崖道（H）の巻物を拾う ③街道の北の鬼を倒す＋崖道へ行く（両方そろって達成）。報告できるようになると画面上に通知。
4. **受注前の達成**：依頼を受ける前に B 北の鬼を倒したり H の巻物を拾ったりしてから受けると、**受けた時点で「報告できる」**になります（自動で受注・報酬はしません）。
5. **報告**：村の娘に話す →「「…」を報告して報酬を受け取る（徳 30）」で徳 +30（1 回だけ）。お地蔵様で成長に使えます。
6. **道による会話の違い**：標準だけ・困難だけ・両方を通って C まで行ったあとで、案内の老人の話が変わります（旅立ちでは経路を推測しません）。
7. **章クリア**：C の仮章ボスを倒すと「第一章（試遊） クリア！　払い戻し権利 +3」（上限 6。上限なら「増えません」）。次章へは飛ばされず、その場で続けられます。章クリア後も未報告の依頼は報告できます。
8. **章クリア後の再開**：メニューから終了 → タイトルで `C`（つづきから）。最後に登録したお地蔵様から始まり、ボスは復活せず、章クリア・権利・依頼はそのまま。
9. 死亡・休息・旅立ち・エリアの行き来・再起動で、受けた依頼と受領済みが消えないこと。

## 5. 見てほしいところ（人間確認。仕様 §12）

1. **文字の読みやすさ**：会話の文字の大きさ・行の長さ・ページの区切り。
2. **操作の理解**：話しかけ方・次へ・選択・閉じる が迷わず分かるか。選択肢をマウスでクリックしても選べるか（自動テストはボタンの当たり判定だけを置き換えているため、ここで見る）。
3. **報告先の明確さ**：どの依頼を誰に報告すればよいか、依頼一覧と通知で分かるか。
4. **道の特徴**：案内の老人の話から、標準ルート（平らな街道・鬼が多い）と困難ルート（崖道・待ち伏せ・近道）の違いを判断できるか。
