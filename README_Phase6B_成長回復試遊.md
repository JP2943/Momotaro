# Phase 6B 成長・回復試遊 — 触りかた

**浅い成長ツリー（三方向 × 3 段の 9 ノード）・払い戻し・きびだんごの使用**を確かめるための試遊。
P6A と同じ A–B–C の 3 エリアを、**P6B 専用の campaign・Data・Scene・保存スロット**で作り直したものです。
仮素材・仮 UI・仮数値のままです。完成版の戦闘バランスや全ツリーではありません（後続課題 `P6B_後続課題.md`）。

仕様の正本は `桃太郎プロジェクト P6B 成長ときびだんご実装仕様 v1.0.md`。受入の記録は `P6B_統合受入結果.md`、
受入条件との対応は `P6B_受入条件対応表.md`、保存項目は `P6_SaveInventory.md`。P6A の触りかたは `README_Phase6A_進行保存試遊.md`。

## 1. 起動

`Scenes/Tests/Phase6B/SCN_Phase6B_Title.unity` を開いて Play。タイトルの操作は P6A と同じ（`N` はじめから／`C` つづきから。パッド可）。

再生成・検査はメニューから（ブリッジの op 名も併記）。

- `Momotaro / Phase 6B / Generate Growth World`（`build-phase6b-world`）… 3 エリア・タイトル・9 ノード・カタログを作り直す。P6A の生成物には触れない
- `Momotaro / Phase 6B / Validate Growth World`（`validate-phase6b-world`）… P6A と同じ配置・campaign 検査に加え、9 ノードの費用・効果・前提、
  きびだんご・払い戻し・章・保存スロット・入力割当を検査する
- ブリッジ `p6b-player-smoke` … Windows ビルドを作り、別プロセスで成長・払い戻し・きびだんご使用 → 正常終了 → Continue の復元を確かめる

保存は P6A と別のスロット（`p6b_slot0`）です。P6A の保存には触れません。

## 2. 操作（P6A に足したもの）

| したいこと | キーボード | パッド |
|---|---|---|
| **きびだんごを食べる** | **`F`** | **左トリガー（LT）** |

**割当の選びかた（記録 001 §4）**：既存の Gameplay・UI・Dialogue の割当と、直接読んでいるキー（R＝P3.5 の Retry、Y／N／C／T／Q、数字）と
重ならない空きから選びました。既存の `UseKintan`（Q／十字下）は十字下が移動と重なるので使っていません。
入力は既存の入力（`PlayerInputAdapter` → `PlayerInputState` の押下ラッチ）に足してあり、キーを別系統で直接読んではいません。

## 3. 成長の木

| 列 | 1 段目（前提なし） | 2 段目 | 3 段目 |
|---|---|---|---|
| 体力 | 体力 一：最大 HP +10（徳 20） | 体力 二：最大 HP +10（40） | 滋養：きびだんご回復量 +5（30） |
| 攻撃 | 剛剣 一：刀の HP ダメージ倍率 +0.10（20） | 剛剣 二：同 +0.10（40） | 腰袋：きびだんご最大数 +1（30） |
| スタミナ | 持久 一：最大スタミナ +10（20） | 崩し：通常攻撃の体幹削り倍率 +0.10（40） | 養生：きびだんご回復量 +5（30） |

- 三方向を自由に混ぜて取れます（排他なし）。全取得 270。**A の初到達で徳 300**（この試遊だけの一度きり報酬）。
  普通敵 1・遭遇戦 30・発見 15 など、実際の探索の報酬でも増えます。
- 倍率は足し算（全取得で刀 1.20・体幹 1.10）。刀の倍率は**通常攻撃の各段と必殺**の HP ダメージに、体幹の倍率は**通常攻撃だけ**に掛かります。
  犬丸・環境・ガード消費・ジャストガードの体幹反射・必殺の体幹には掛かりません。
- 取得したら**その場で休息**します（新しい上限まで全回復・きびだんご補充・普通敵が戻る・保存）。
- 木の表示：［取得済み］［取得可能］［徳不足］［条件不足］。選んだノードの効果・費用・前提と、取得後（払い戻し後）の能力値が下に出ます。
- 確認は**「いいえ」が選ばれた状態**で開きます（決定の連打で取得 → 払い戻しと進まない）。

**払い戻し**：取得済みで、ほかの取得済みノードの前提になっていない**末端**だけを 1 回 1 つ。権利は初期 3（上限 6。章クリアで +3 の接続口あり。
本番の章はまだ無い）。返ってくるのは**取得時に実際に払った徳**。払い戻しのあとも休息します（上限が下がれば残数もそこまで）。

## 4. きびだんご

| 項目 | 値（Data `SO_AreaCatalog_P6B` で変更可） |
|---|---|
| 最大数 | 3（腰袋で +1） |
| 回復量 | 50（＝成長なしの基礎最大 HP 100 の半分。成長後の最大 HP には連動しない。滋養・養生で +5 ずつ） |
| 全動作 | 2.0 秒。**1.5 秒で回復と残数 −1 が同時に入る**（そこで保存） |
| 使用中 | 歩く速さは 20%。向きは変えられる。攻撃・必殺・ガード・回避・追加使用・調べるはできない。キャンセル不可 |
| 開始できるとき | 生きていて、立ち止まっているか歩いているとき・HP が最大でない・残数 1 以上。戦闘中・遭遇戦中も可 |
| 中断 | 1.5 秒より前に**実際に攻撃を受けたら**中断（回復も消費もなし）。犬丸が完全にかばえば続く。無敵中の接触では止まらない |

- 使用中は通常のエリア移動をしません。使い終われば、出口の方へ**押し続けたまま**移れます（離して押し直す必要はありません）。
- 使用中に押した攻撃・回避などは、終わった直後に勝手に出ません。押しっぱなしのガードは一度離してから。
- Pause・メニュー中は時間が止まります。

画面左下に「きびだんご 残数／上限・HP」と、使用中の進み具合（1.5 秒の印つき）を出します。

## 5. 見てほしいところ（人間確認。仕様 §11 の 4 点）

1. **成長の分かりやすさ**：木の並び・状態の札・取得後の能力値の表示で、何が増えるかが分かるか。
2. **回復中の低速移動と行動制限**：2 秒の間の 20% 移動と、攻撃・回避ができないことが窮屈すぎないか。
3. **1.5 秒確定と被弾中断**：回復の入る瞬間が分かるか。被弾で中断されたことが分かるか。
4. **境界での動き**：出口で食べたとき、食べ終わってからそのまま押し続けて移れるか。
