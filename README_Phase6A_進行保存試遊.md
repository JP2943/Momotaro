# Phase 6A 進行・保存試遊 — 触りかた

**進行・休息・保存の基盤**を確かめるための最小 campaign（A–B–C の 3 エリア）。
成長ツリー・回復ゲームプレイ・章イベントはまだ無く、**仮素材・仮 UI** のままです。見た目ではなく、
「死んでも何が残るか」「お地蔵様で何が起きるか」「やめて再開したら元に戻るか」を見るためのもの。

仕様の正本は `桃太郎プロジェクト P6先行実装仕様 v1.0 承認用.md` と `桃太郎プロジェクト コアループ定義 v1.0.md`。
受入の記録は `P6A_統合受入結果.md`、受入条件との対応は `P6A_受入条件対応表.md`、性能は `P6A_性能測定記録.md`、
残件は `P6A_後続課題.md`、保存項目は `P6_SaveInventory.md`。

---

## 1. 起動

`Scenes/Tests/Phase6A/SCN_Phase6A_Title.unity` を開いて Play。

| キー | タイトルでの意味 |
|---|---|
| `N` | はじめから（保存があるときは確認が出る。`Y` で前の冒険を退避して始める） |
| `C` | つづきから（保存を検証して再開。読めないときは理由を出す。**黙って新しく始めない**） |

**パッドでも選べます**（タイトル・お地蔵様・メニュー・保存失敗の選択肢すべて）：十字キー／左スティックの上下で選び、
A（×）で決定、B（○）で戻る。キーボードの ↑↓・Enter でも同じです。選んでいる項目は「▶」と色で示します。
仮 UI は文字・枠とも 1.5 倍で表示します。保存があるときのタイトルは「つづきから」が、New Game の確認は「いいえ」が選ばれた状態で開きます。

再生成は Unity のメニューから（手で直さず作り直す）。

- `Momotaro / Phase 6A / Generate Progression World` … 3 エリア・タイトル・Data を作り直す
- `Momotaro / Phase 6A / Validate Progression World` … 配置（P5.5 と同じ基準）と campaign の整合を検査する
- `Momotaro / Phase 6A / Player Build Smoke (Windows)` … Windows ビルドを作り、別プロセスで保存→再開と保存性能の計測を自動で走らせる（数分）

> 未保存の変更がある Scene が開いていると、生成と検査は**何もせずに断ります**。

保存先は Editor では `persistentDataPath/saves_editor`、ビルドでは `persistentDataPath/saves`（1 スロット 2 世代）。

## 2. 操作

| したいこと | キー |
|---|---|
| 移動 | `W` `A` `S` `D` |
| 攻撃 | `J` |
| 調べる（お地蔵様・配置物・調査地点・レバー） | `E` |
| 死亡後の再開 | `Enter` |
| メニュー（タイトルへ／終了） | `Esc`（パッドは Start）→ `T`（タイトルへ）／`Q`（終了）／`Esc`（戻る）。上下と決定でも選べる |

**お地蔵様を調べたあと**（メニュー表示中）：

| キー | 意味 |
|---|---|
| `1` | 休息（全回復・きびだんご補充・**普通敵が戻る**） |
| `2` | 成長（検証用：最大 HP +10、徳 20。成立したらそのまま休息） |
| `3`〜`6` | 旅立ち（登録済みの別のお地蔵様へ。着いたら休息） |
| `Esc` | 閉じる |

**調べただけでは回復しません。** 登録（死んだらここへ戻る）と保存だけです。

## 3. 地図

東西に並んでいます。境界はスライドで渡ります（P5.5 と同じ）。

| エリア | 置いてあるもの |
|---|---|
| A（はじまり） | お地蔵様（初期の再開地点）、普通敵 2 体（倒すと徳 1。**移動では戻らず、休息・死亡・旅立ちで戻る**）、レバーと門、調査地点 |
| B | 北と南に**別々の遭遇戦**（戦闘中でも出入口から**撤退できる**。戻ると最初から）、北をクリアすると開く小部屋（巻物：発見 15）、強壮薬（所持品。上限 3） |
| C（ボス前） | お地蔵様、調査地点、仮ボス（既存の精鋭敵。**一度倒したら戻らない**） |

徳の仮の値：初到達 B・C 10、個別撃破 1、遭遇戦の初回クリア 30、発見 15（仕様 §11 の例。完成版経済ではありません）。

**死にやすくしてあります（P6 のテスト専用。2026-10-02 オーナー指示）。** 死亡と再開を何度も試せるように、
この検証 campaign だけ**敵の攻撃力を 2 倍**、**主人公の最大 HP を基礎値の半分**にしています（成長の +10 は半分にした後に足す）。
本編・P3.5〜P5.5 の試遊には効きません。値はカタログ `Data/Tests/Phase6A/SO_AreaCatalog_P6A.asset` の
「テスト専用の調整」（`TestEnemyAttackScale`／`TestPlayerMaxHpScale`）で、1 にすれば元に戻ります（Builder で作り直すと 2／0.5 に戻ります）。

## 4. 見てほしいところ（人間確認）

自動テストでは確かめられないものだけです。

1. **歩いているとき・連戦中に引っ掛かりが無いか。** 保存は撃破・到着・登録・開通などのたびに裏で走ります。画面の右下に「保存中…」が一瞬出ることがあります。
2. **保存の表示が分かるか。** 失敗したときは右下に「保存できていません」と「もう一度」が出ます。終了・タイトルへ戻るときに失敗すると、選択肢（もう一度／ゲームへ戻る／保存せずに終了）が出ます。
3. **死亡と中断の違いが分かるか。** 死ぬと最後に**調べた**お地蔵様へ全回復で戻ります（徳・開通・クリアは残る、普通敵は戻る）。やめて「つづきから」で始めると、**やめた場所の近くの安全な入口**から、HP や犬丸の状態はそのままで始まります（戦闘中にやめたら、その遭遇戦は最初から）。
4. **攻撃の剣閃が見えるか。** P5／P5.5 の試遊では出ていなかったものです（原因と修正は記録 004 §6）。北の壁際で欠けないかも見てください（未計測）。
5. **撤退の感触。** B の遭遇戦の途中で西の出入口から A へ出られます。戻ると遭遇戦は最初から、倒した分の徳は残ります。

## 5. 既知の制限

- 成長は検証用の 1 項目だけ。きびだんご・消耗品は**使えません**（数と補充だけ）。
- UI は仮（IMGUI）。
- P5／P5.5 の試遊 Scene の剣閃は直していません（`P6A_後続課題.md` F01。オーナー判断）。
- ヒット SE・足音などは P5 系の Area にまだありません（F03）。
