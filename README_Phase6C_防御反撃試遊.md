# Phase 6C ジャスト回避・防御反撃試遊 — 触りかた

**ジャスト回避（回避の出だしで敵の攻撃を避ける）→ 次の通常攻撃 1 段の強化**と、**通常ガード不可の攻撃をジャスガで受ける**ことを確かめる試遊。
P6B と同じ A–B–C の 3 エリア・成長・きびだんごを、**P6C 専用の campaign・Data・Scene・保存スロット**（`p6c_slot0`）で作り直したものです。
仮素材・仮 UI・仮数値のままです（受付 0.12 秒・1.5 倍・2 秒は第一章ボスの試遊 P9a で調整）。

仕様の正本は `桃太郎プロジェクト P6C ジャスト回避と防御反撃実装仕様 v1.0.md`。受入の記録は `P6C_統合受入結果.md`、受入条件との対応は
`P6C_受入条件対応表.md`、後続は `P6C_後続課題.md`。P6B の触りかたは `README_Phase6B_成長回復試遊.md`。

---

## 1. 起動

`Scenes/Tests/Phase6C/SCN_Phase6C_Title.unity` を開いて Play（`N` はじめから／`C` つづきから）。

- `Momotaro / Phase 6C / Generate Just Evade World`（ブリッジ `build-phase6c-world`）… 3 エリア・タイトル・Data を作り直す。P6A・P6B の生成物には触れない
- `Momotaro / Phase 6C / Validate Just Evade World`（`validate-phase6c-world`）… P6B と同じ検査＋ジャスト回避の設定・ガード不能の可否・表示と音の配線
- ブリッジ `p6c-player-smoke` … Windows ビルドを作り、別プロセスで実入力のジャスト回避・反撃 → 正常終了 → Continue を確かめる

## 2. 操作（新しいボタンは無い）

| したいこと | キーボード | パッド |
|---|---|---|
| 回避（ジャスト回避） | `Space`（＋方向） | B（○） |
| 攻撃 | `J` | X（□） |
| ガード（押した瞬間がジャスガ） | `K` | RB |

画面左上に操作説明、ガード不能の予告中は「！通常ガード不可・ジャスガ可能」、強化を持っている間は「反撃 ×1.5　残り n 秒」とバーを出します。
成功すると「ジャスト回避！」と、専用の音・点滅・小さな揺れが出ます。

## 3. 規則（仮値。Data `SO_Step_Momotaro` で変更可）

| 項目 | 値 |
|---|---|
| ジャスト回避が成り立つ時間 | ステップ開始から **0.05〜0.12 秒未満**（受付 0.12 秒と、ステップの無敵 0.05〜0.20 秒の重なり。0.07 秒） |
| 成功の条件 | 敵の攻撃が実際に当たる瞬間であること。予備動作の近くで避けただけ・もう範囲外・被弾後の無敵だけ・環境の接触では成功しない。1 回の回避につき 1 回 |
| 報酬 | **次に始めた通常攻撃の 1 段だけ** HP ダメージ 1.5 倍（成長の刀倍率と掛け算）。2 秒以内に始めた段が対象。体幹・ひるみ・必殺・犬丸は強化しない |
| 消費 | 攻撃の段が実際に始まったとき（空振り・被弾で止められても戻らない）。持っている間に必殺・ガード・回避・きびだんごをしても消費しない |
| 蓄積 | しない（別の成功で残り 2 秒へ戻るだけ） |
| 敵への影響 | **無い**（旧仕様の体幹反射・強制ひるみは撤去。敵の攻撃は続く。位置を変えて当てに行くのが利益） |
| 消える | 時間切れ・死亡・休息・成長・払い戻し・旅立ち・通常エリア移動の成功・Continue／New Game。保存しない |
| 通常ガード不可（赤い予告） | 通常ガードでは受けられない。**ジャスガは成立**して体幹反射（既存の規則）。回避も可 |

敵：A の普通敵（近接）・B 北の 2 体・B 南の遠距離（矢）・C の仮ボス（精鋭。通常／強／突進／**通常ガード不可の突き**）。既存の敵 AI と Data のままです。

## 4. 試してほしいこと（仕様 §9）

1. C の仮ボスの赤い予告の突きを、K 押しっぱなしで受ける（失敗）→ 同じ攻撃を当たる直前に K を押して受ける（ジャスガ成功）。
2. 同じ攻撃を早めの回避とジャスト回避で避け、そのあとの攻撃のダメージを比べる。
3. ジャスト回避の直後も敵の攻撃は続く（止まらない）。
4. 空振り・時間切れ・複数の敵・成長ありの反撃。
5. きびだんご中は回避・ガードできない、エリア移動後の表示、保存して Continue。

## 5. 見てほしいところ（人間確認。仕様 §10）

1. **成功が分かるか**：ジャスト回避が成り立った瞬間を、音・点滅・文字で認識できるか。
2. **通常回避と使い分けられるか**：0.07 秒の重なりが狙えるか、普通の回避との違いが分かるか。
3. **ジャスガと回避で違う利益**：ジャスガで体幹を崩す・ジャスト回避で HP を削る、の違いが感じられるか。
