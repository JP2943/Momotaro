# 桃太郎プロジェクト — Phase 3.5 戦闘縦切り 試遊版 README

戦闘の「縦切り（vertical slice）」試遊版です。主人公 1 体を操作し、4 ウェーブの敵（骸骨剣士・骸骨弓兵・侍骸骨）を連続で相手にします。目的はストーリーやマップではなく、**戦闘の手応え・操作感・視認性を確認していただくこと**です。歯応えや気持ちよさ、分かりにくさを率直に教えてください。

---

## 動作環境

- Unity **6000.3.20f1**（URP）
- 入力はキーボード前提（リトライのみゲームパッドにも対応）
- プロジェクトを Unity で開いて Editor 上で Play します（実行ファイル配布ではありません）

---

## 起動手順

1. Unity でプロジェクトを開く。
2. （初回・スクリプト更新後など、シーンが最新でない場合）メニュー **Momotaro → Phase 3.5 → Generate Combat Trial** を実行して試遊シーンを生成・更新する。
   - 生成先: `Assets/_Project/Scenes/Tests/SCN_Phase35_CombatTrial.unity`
   - VFX/SE 素材が揃っていないと安全のため生成に失敗し、シーンは書き換えません（Console にメッセージ）。
3. 上記シーンを開く。
4. **Play** を押す。Wave 1 から自動で連続進行します。

> シーンが既に最新であれば手順 2 は不要です。パラメータ調整やスクリプト変更を反映したいときに再生成してください。

## 操作（キーボード）

| 操作 | キー | 補足 |
|---|---|---|
| 移動 | W / A / S / D | |
| 攻撃（3 段コンボ） | J | 連打で 1→2→3 段 |
| ガード／ジャストガード | K | 攻撃が当たる直前に合わせると**ジャストガード**成立 |
| ステップ回避／ジャスト回避 | Space | 発生直後のタイト窓で無敵回避すると**ジャスト回避**成立 |
| 必殺技 | L | 長押しでタメ、離すか最大保持で発動 |
| ポーズ | Esc | |
| リトライ（勝敗確定後のみ） | Enter または R | ゲームパッド: Start / A |

画面右下にも同じ操作ガイドが常時表示されます。

---

## 戦い方のヒント（＝確認してほしい手応え）

- **通常コンボ**は 3 段。段が進むほどヒット音が強くなります。
- **ガード不能攻撃**（主に侍骸骨）は頭上に**赤い予告**が出ます。ガード／ジャストガードは効きません。**ステップ回避が正解**です。
  - 予告に対して発生直後に Space を合わせると**ジャスト回避**が成立し、相手の体幹を削って反撃の隙を作れます（専用の効果音・閃きが出ます）。
- **ジャストガード**成立でも相手の体幹を削り、近接の相手を短くひるませます。
- **必殺技（L）**は前方へ踏み込みながら判定がしばらく持続します。発動後の後隙は**攻撃（J）またはステップ（Space）でキャンセル**できます（爽快感重視の調整）。

## コンテンツ（Wave 構成）

| Wave | 編成 |
|---|---|
| 1 | 骸骨剣士 ×1（近接） |
| 2 | 骸骨弓兵 ×1（遠距離） |
| 3 | 骸骨剣士 ×2 ＋ 骸骨弓兵 ×1（混成） |
| 4 | 侍骸骨 ×1（強敵。ガード不能攻撃を持つ） |

各 Wave を全滅させると短い幕間（約 3 秒）を挟んで次の Wave へ進みます。幕間で HP・スタミナは全回復します（試遊用の仮仕様）。最終 Wave 全滅で **Victory**、主人公が倒れると **Defeat**。結果パネル表示後、Enter / R でリトライできます。

---

## 既知の制約（試遊版であることの前提）

- **頭上の HP／体幹（スタミナ）バーは仮 UI** です（開発用の簡易表示）。完成版の HUD デザインではありません。仕組み上つねに最前面へ描画されるため、ガード不能予告との重なりは予告の位置と透過で回避しています。
- **撃破演出は暫定**です。撃破後は約 1 秒ダウン姿勢を保持してからフェードします。最終的な消滅・死体表現は今後の対応です。
- **敵は 3 種のみ**（骸骨剣士・骸骨弓兵・侍骸骨）で、**ボスはいません**。Wave 編成は上記 4 固定です。
- **一部の VFX／SE は試遊用の暫定**です。素材が未割当の演出は無音・非表示で安全に継続します（ジャストガードの閃光など）。
- **各種の数値は試遊調整中**です（必殺技のタメ／射程／持続／踏み込み、ジャスト回避の受付窓・反撃量、ジャストガードの受付、SE の音量、予告の高さ、ダウン保持時間 など）。これらは Data／調整値に集約しており、感触に応じて変更します。
- カメラは俯瞰固定です。
- 操作ガイドはキーボード基準の表示です（リトライのみゲームパッド対応）。
