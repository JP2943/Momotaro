# Phase 4 仲間試遊版 — 触りかた

犬丸（最初の仲間）を入れた試遊環境の手順書。仮素材のままなので、見た目ではなく**振る舞い**を見るためのもの。
探索の仕様は `Momotaro_P4_Claude_Implementation_Request_v1.0.md`（§4〜§6・§13）が正本。

---

## 1. どの Scene を開くか

用途が違う 2 つがある。どちらも Builder が機械生成するので、手で直さず**作り直す**のが正しい直し方。

| Scene | 用途 | 敵の出しかた |
|---|---|---|
| `Assets/_Project/Scenes/Tests/SCN_Phase4_CompanionTrial.unity` | **通しで遊ぶ**。自由探索 → 明示開始 → 4 Wave → 勝敗 → Retry。徳の HUD がある | **Play 直後は敵なし（自由探索）**。Enter／Start で Wave1 から始まる |
| `Assets/_Project/Scenes/Tests/SCN_Phase4_CompanionField.unity` | **落ち着いて挙動を見る**。敵を任意に出せる | `Phase4Systems/EnemyTestField` の Context Menu から編成を選ぶ |

再生成は Unity のメニューから（ブリッジの `run-op` でも同じものが動く）。

- `Momotaro / Phase 4 / Generate Companion Trial`（試遊 Scene を **Build Settings にも登録**する。Retry の再読込に必要）
- `Momotaro / Phase 4 / Generate Companion Field`
- 犬丸そのものを作り直すなら `Momotaro / Phase 4 / Generate Inumaru Prefab`

検査は `Momotaro / Phase 4 / Validate Companion Trial`（または `... Field`）。
Scene を手で編集したあとは、これを 1 回押しておくと配線漏れがその場で分かる。

## 2. 操作

主人公の操作は Phase 3.5 の試遊版と同じ。仲間まわりで増えたのは次の 2 つ。

| 操作 | 何が起きるか |
|---|---|
| **E キー**（ゲームパッドは南ボタン＝既存の Interact） | 目の前の調査地点を**犬丸に調べさせる**。押下 1 回で 1 依頼。押しっぱなしで連続実行はしない |
| **Enter**（ゲームパッドは Start） | **戦闘を始める**（試遊専用の明示開始。P3.5 の自動開始は Scene 側で切ってある） |
| Enter / R | Retry（結果表示中のみ。3.5 から） |

- 「待て／ついてこい」の指示は **P4 の範囲外**（詳細仕様 §3.2）。T キーの割当は撤去した。
- `CompanionSkill`（U／LB）は戦闘スキルの予約のまま、何も割り当てていない。

## 3. 見るべきところ

### 3.1 地点マーカーと短文 UI（仮表示）

調査地点には地面の**輪**と頭上の**文字**がある。色だけに頼らず、文字で状態が分かる。

| 頭上の文字 | 意味 |
|---|---|
| **？** | 未調査。まだ近づいていない |
| **E / 南ボタン：調べる** | いま E を押すとこの地点を調べる（輪が白くなる） |
| **犬がいれば何か見つかりそうだ** | 未加入の仲間が必要な地点（右奥の 1 つ）。押しても調査済みにならない |
| **そこへは行けない** | 壁の向こうの地点（手前の 1 つ）。受付前に拒否される |
| **調査中** | 犬丸がこの地点へ向かっている／調べている |
| **済** | 調査済み。もう一度押すと「ここは調べ終えた」 |

画面下中央に同じ案内文が出る。その上の行に、受理・発見・拒否・中断の短文が約 2 秒出る。
画面上中央には、戦闘を始めるまで「Enter / Start：戦闘を始める」が出る。

### 3.2 犬丸の色（仮表示）

| 色 | 状態 |
|---|---|
| 白 | 追従 |
| 黄 | 敵へ接近 |
| 橙 → 赤橙 → 鈍い橙 | 攻撃の予兆 → 判定中 → 後隙 |
| 青 | ガード |
| 淡青 | 回避 |
| 桃 | 守護（主人公をかばった。一瞬なので短く光る） |
| **緑** | **調査中（探索）**。頭上に「移動」「調査中」の文字 |
| 暗い赤灰 | ひるみ |
| 暗灰・半透明 | ダウン |
| 淡黄 | 復帰待ち |
| 水色・半透明 | ワープ |

ダウン・退場中に調べさせると、本体はそのまま倒れていて、**緑の分身（表示代理）**が代わりに歩いて調べ、
「移動 → 調査中 → 帰還」の文字を付けて戻ってくる。分身が出ている間、本体の表示は消える（同時に 2 体は見せない）。

### 3.3 順番に試すと分かりやすいこと（試遊 Scene）

1. **自由探索** — Play 直後は敵が居ない。犬丸が追従している。画面上に「Enter / Start：戦闘を始める」。
2. **調べる（正常）** — 左手前の輪へ近づく。頭上が「E / 南ボタン：調べる」に変わったら E。
   犬丸が緑になって輪へ歩き、約 1 秒調べ、「犬丸が痕跡を見つけた」と出て「済」になる。
3. **調査済み** — 同じ輪でもう一度 E。「ここは調べ終えた」。犬丸は動かない。
4. **壁の向こう** — 手前中央の輪（壁の裏）へ近づいて E。「そこへは行けない」。予約もされない。
5. **未加入** — 右奥の輪へ近づいて E。「犬がいれば何か見つかりそうだ」。調査済みにならない。
6. **離れて中断** — 右手前の輪で E を押してすぐ走って離れる（3m 超）。「離れすぎて、調査をやめた」。もう一度近づいて E で再依頼できる。
7. **ダウン中に調べる** — Field Scene で犬丸の HP を削り切ってから輪で E。本体は倒れたまま、緑の分身が調べに行って戻る。
   **HP は回復しない**（探索は戦闘値に触らない）。
8. **調査中に戦闘開始** — E で調べさせている最中に Enter。調査をやめ（「戦闘が始まり、調査をやめた」）、Wave1 が湧く。
9. **戦闘** — 犬丸が黄→橙→赤橙と進んで殴る。敵の攻撃予兆に青（ガード）／淡青（回避）。主人公の近くで被弾すると桃（守護）。
10. **先制すると狙われる** — 気づいていない敵に犬丸が先に当てると、その敵は**犬丸を狙う**（実測 0.7 秒で切替）。
    逆に主人公が先に当てれば主人公が狙われる。「口火を切った側がその戦闘を引き受ける」。
    そのまま主人公が殴り続ければ、**約 1 秒で狙いが主人公に戻る**（仲間のヘイトには天井があるため）。
11. **4 Wave → Retry** — 勝てば徳 94。Retry で Scene が読み直され、**敵なしの自由探索**から始まる。調べた「済」も消える。

### 3.4 「これは仕様です」というもの

- **戦闘中・Wave 幕間は調べられない**（「戦闘中は調べられない」）。依頼を予約もしない。
- **主人公が攻撃・Step・被弾している最中は E を受けない**。立ち止まるか歩いているときだけ。
- **調べても何も出ない**。地点は「調べ済み」になり発見 ID が通知されるだけ。中身は P5 のマップ・探索基盤。
- **回避に移動が無い**。いまの回避は無敵時間だけ。
- **仲間は 1 体だけ**。猿・雉は P8。未加入地点はその確認経路。
- **同時に近い 2 つの命中は、届いた順で結果が変わる**ことがある（守護の既知の仕様。`GuardianHitOrderTests`）。
- **数値は仮**（範囲 1.5m／継続 3m／調査 1 秒／移動タイムアウト 3 秒）。犬丸のスプライトが出来てから見直す。
- **口火を切った側が最初に狙われる**。強さは各敵 Prefab の `EnemyThreatTracker / _settings / _firstStrikeThreat`
  （既定 50。犬丸は獲得倍率 1.5 が乗って実効 75）。
- **ただし仲間のヘイトには天井がある**ので、主人公が本気で殴れば狙いは戻る（実測 1.0 秒）。
  天井は `SO_Companion_Inumaru / _maxAcquiredThreat`（既定 75。0 は無制限）。主人公に天井は無い。
  天井を 62.5 より下げると先制しても狙いを奪えなくなる（テストが検出する）。

## 4. 気になったときに見るところ

- **犬丸が何もしない** → `CompanionActivityContext` が置かれ、戦闘 Session と試遊段階（TrialStage）が
  割り当たっているか。未配線だと安全側に全停止する（Validator が検出する）。
- **E を押しても何も起きない** → 頭上の文字が「？」のままなら範囲外（1.5m）。`Investigation/InvestigationInput` が
  調停役を指しているか（Validator が検出する）。
- **Enter で戦闘が始まらない** → `Investigation/TrialCombatStartInput` があるか。Retry 待ち中の Enter は Retry に取られる。
- **Retry で Scene が戻らない** → 試遊 Scene が Build Settings に無い。Builder を実行し直す（登録も行う）。
- **近づくのに攻撃しない** → `CompanionCombatController` の `_logDecision` を有効にすると判断の入力値が Console に出る。
- **敵に狙われない** → 与ダメージが 0 だとヘイトが乗らない。Data の `AttackPower` を確認。

## 5. フィードバックの出しかた

数値は **Data が正本**で、Inspector から変えられる。触った値は Play を止めると戻るので、残したい調整は Asset を直接編集する。

- 探索：`Assets/_Project/Data/Exploration/SO_Investigation_Trial.asset`（Interact 範囲・継続範囲・到着距離・移動タイムアウト・調査秒・帰還表示の上限）
- 犬丸：`Assets/_Project/Data/Companions/SO_Companion_Inumaru.asset`（移動速度・攻撃力・守護範囲・CD・獲得ヘイト倍率／上限）

Play 中に探索 Data を変えても**実行中の依頼には反映されない**（開始時に Snapshot を取る）。次の依頼から効く。
Data 検証は `Momotaro / Data / Validate All`（ブリッジの `validate-project-data`）。
