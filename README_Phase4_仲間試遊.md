# Phase 4 仲間試遊版 — 触りかた

犬丸（最初の仲間）を入れた試遊環境の手順書。仮素材のままなので、見た目ではなく**振る舞い**を見るためのもの。

---

## 1. どの Scene を開くか

用途が違う 2 つがある。どちらも Builder が機械生成するので、手で直さず**作り直す**のが正しい直し方。

| Scene | 用途 | 敵の出しかた |
|---|---|---|
| `Assets/_Project/Scenes/Tests/SCN_Phase4_CompanionTrial.unity` | **通しで遊ぶ**。Wave・勝敗・Retry・徳の HUD がある | Wave が自動で出す（Play すると Wave1 から） |
| `Assets/_Project/Scenes/Tests/SCN_Phase4_CompanionField.unity` | **落ち着いて挙動を見る**。敵を任意に出せる | `Phase4Systems/EnemyTestField` の Context Menu から編成を選ぶ |

再生成は Unity のメニューから。

- `Momotaro / Phase 4 / Generate Companion Trial`
- `Momotaro / Phase 4 / Generate Companion Field`
- 犬丸そのものを作り直すなら `Momotaro / Phase 4 / Generate Inumaru Prefab`

検査は `Momotaro / Phase 4 / Validate Companion Trial`（または `... Field`）。
Scene を手で編集したあとは、これを 1 回押しておくと配線漏れがその場で分かる。

## 2. 操作

主人公の操作は Phase 3.5 の試遊版と同じ。仲間まわりで増えたのは 1 つだけ。

| 操作 | 何が起きるか |
|---|---|
| **T キー**（ゲームパッドは △／Y） | 犬丸への指示を「ついて来い ⇄ ここで待て」で切り替える |
| Enter / R | Retry（結果表示中のみ。3.5 から） |

指示は Inspector からも出せる。Play 中に犬丸を選び、`CompanionOrders` を右クリック →
「Order: ついて来い」「Order: ここで待て」。

> **入力の割り当ては仮**。本編の操作体系が決まっていないので、試遊で確かめられる最小の口として
> 1 キーに割り当ててある。

## 3. 見るべきところ

### 3.1 状態の色（仮表示）

犬丸のシルエットの色が状態を表す。スプライトが完成するまではこれが唯一の手がかり。

| 色 | 状態 |
|---|---|
| 白 | 追従 | 
| 灰 | 待機（「ここで待て」） |
| 黄 | 敵へ接近 |
| 橙 → 赤橙 → 鈍い橙 | 攻撃の予兆 → 判定中 → 後隙 |
| 青 | ガード |
| 淡青 | 回避 |
| 桃 | 守護（主人公をかばった） |
| **緑** | **調査中（探索）** |
| 暗い赤灰 | ひるみ |
| 暗灰・半透明 | ダウン |
| 淡黄 | 復帰待ち |
| 水色・半透明 | ワープ |

### 3.2 順番に試すと分かりやすいこと

1. **追従とワープ** — 走って離れる。隊列位置へ戻ってくる。壁を挟んで大きく離すとワープする。
2. **探索** — 立ち止まる。青い輪（調査地点）へ犬丸が寄っていき、緑になって少し留まり、白へ戻る。
   輪は 3 つあり、調べ終えた地点は灰色になる。
3. **戦闘** — 敵を出す。犬丸が黄→橙→赤橙と進んで殴る。敵のヘイトが犬丸へ乗ると狙われる。
4. **調査の中断** — 犬丸が緑（調査中）のあいだに敵を出す。**調査をやめて戦いに行く**。
5. **防御** — 敵の攻撃予兆に対して青（ガード）になる。ガード不能な攻撃には淡青（回避）。
6. **守護** — 犬丸を主人公の近くに置いた状態で主人公が被弾する。犬丸が桃になり、主人公の HP が減らない。
   連続では起きない（クールダウンがある）。
7. **指示** — T を押して灰（待機）にする。**主人公が離れても付いてこない**。
   その状態で敵を犬丸へ近づけると、**逃げも寄りもしないが目の前の敵は殴る**。もう一度 T で追従へ戻る。
8. **ダウンと復帰** — 犬丸の HP を削り切る。暗灰になり、しばらくして復帰する。

### 3.3 「これは仕様です」というもの

試遊中に不具合に見えるが、そう決めてあるもの。

- **待機中でも殴り返す**。指示は「何をしに行くか」を止めるもので、自衛は止めない。
- **回避に移動が無い**。いまの回避は無敵時間だけで、実際には避けて動かない（未実装）。
- **調べても何も出ない**。調査地点は「調べ済み」になるだけ。中身は P5 のマップ・探索基盤の話。
- **仲間は 1 体だけ**。猿・雉は P8。誰が庇うかの調停も複数体が入ってからになる。
- **同時に近い 2 つの命中は、届いた順で結果が変わる**ことがある（守護の既知の仕様。
  `GuardianHitOrderTests` に固定してある）。

## 4. 気になったときに見るところ

- **犬丸が何もしない** → `Phase4Systems/CompanionActivityContext` が置かれ、戦闘 Session が
  割り当たっているか。未配線だと安全側に全停止する（Validator が検出する）。
- **調べに行かない** → 調査地点が主人公から遠すぎる可能性。犬丸 Data の `InvestigateLeashDistance`
  （既定 6m）の外にある地点へは行かない。Validator が警告する。
- **近づくのに攻撃しない** → 犬丸の `CompanionCombatController` の `_logDecision` を有効にすると、
  判断の入力値（距離・角度・クールダウン・攻撃設定）が Console に出る。
- **敵に狙われない** → 与ダメージが 0 だとヘイトが乗らない。Data の `AttackPower` を確認。

## 5. フィードバックの出しかた

数値（気付く範囲・調べる時間・紐の長さ・攻撃力・クールダウン）は **Data が正本**で、
Inspector から変えられる。触った値は Play を止めると戻るので、残したい調整は
`Assets/_Project/Data/Companions/SO_Companion_Inumaru.asset` を直接編集する。

なお `InvestigateLeashDistance` は `WarpDistance` より**短くする必要がある**
（超えると、調べに行った先でワープの条件が成立して隊列へ引き戻される）。
Data 検証（`Momotaro / Data / Validate All`）が違反を報告する。
