# Phase 5 探索試遊版 — 触りかた

2 つの仮エリアを行き来し、調査・仕掛け・遭遇戦・探索復帰・死亡再開までを通しで触るための試遊環境。
**仮素材のままなので、見た目ではなく振る舞いを見るためのもの。**
仕様の正本は `Momotaro_P5_Detailed_Spec_v1.1.md`。受入の記録は `P5_統合受入結果.md`。

---

## 1. どこから始めるか

`Assets/_Project/Scenes/Tests/Phase5/SCN_Phase5_ExplorationTrial.unity` を開いて Play。
エリア A の開始点から始まります。

| Scene | 用途 |
|---|---|
| `SCN_Phase5_ExplorationTrial.unity` | **ここから始める。** 常駐サービスを立ち上げて A へ入る |
| `SCN_Phase5_AreaA.unity` | エリア A を直接開く（既定入口から始まる） |
| `SCN_Phase5_AreaB.unity` | エリア B を直接開く |

A・B を直接 Play しても動きます（そのエリアの既定入口から始まります）。
**死亡再開点はどちらから始めても A の開始点**です。

再生成は Unity のメニューから。手で直さず**作り直す**のが正しい直し方です。

- `Momotaro / Phase 5 / Generate Exploration Trial` … Data・3 Scene・地形・NavMesh・Build Settings をすべて作り直す
- `Momotaro / Phase 5 / Validate Exploration Trial` … いま開いている Area Scene を検査する

> 未保存の変更がある Scene が開いていると、生成は**何もせずに断ります**。保存か破棄をしてから実行してください。

## 2. 操作

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| 移動 | WASD | 左スティック |
| 攻撃 | J | □（West） |
| ガード | K 長押し | L1 |
| ステップ | Space | ○（East） |
| 必殺 | L 長押し | R2 |
| **調べる・仕掛ける・扉** | **E** | **×（South）** |
| **再開する**（死亡後） | **Enter** | **×（South）** |
| Pause | Esc | Start |

Interact（E／×）は**1 押しで 1 回**だけ効きます。押しっぱなしでは繰り返しません。

## 3. 2 つのエリアと導線

### エリア A（開始点・死亡再開点）

- **調査地点が 2 つ。** 片方は普通に調べられ、もう片方は**壁越し**なので断られます（断られるのが正しい挙動）。
- **レバーと門。** レバーを E で操作すると門が開きます。開通は記録に残り、往復しても死んでも残ります。
- **開放出入口（東）。** 範囲内で東へ 0.15 秒入力し続けると B へ移動します。触れただけ・押し出されただけでは移動しません。
- 水場と L 字通路があり、カメラ領域が西の大部屋と東の通路で分かれています。

### エリア B（遭遇戦）

- 到着直後の敵は **0 体**。
- 調査地点が 1 つ。
- **道の中ほどに入ると遭遇戦が始まります。** 一時的な境界で区画が閉じ、骸骨剣士 1 体と骸骨弓兵 1 体が湧きます。
- 全滅させると「戦闘終了」の短文が出て探索へ戻り、境界が解けます。
- **扉（西）** を E で開けると A へ戻れます。

## 4. 徳 22 と、死んだあとの挙動

- 初回の遭遇戦を全滅させると **徳は合計 22**（近接 10 ＋ 弓 12）。HUD に出ます。
- **一度クリアした遭遇戦は、往復しても湧き直しません。**
- **死亡すると「再開する」が出ます。** Enter／× で受理され、A の開始点から再開します。
  - **残るもの**：徳、調査済み、門の開通、訪問済み、犬丸の加入。
  - **戻るもの**：主人公と犬丸の HP・CD・短時間の状態（全回復して出直す）。
  - **湧き直すもの**：通常の遭遇戦。もう一度倒せば徳はまた入ります（10 → 死亡再開 → 再戦で 32）。
- 撃破した瞬間の徳は、その戦闘で後から死んでも**取り消されません**。

> 既存の試遊版（Phase 3.5／Phase 4）の「Retry」とは**別物**です。あちらは Scene をまるごと作り直すやり直しで、
> 進行は残りません。P5 の「再開する」は本編と同じ扱いで、既得の進行を保ったまま再開します。

## 5. データは残りません

**アプリを終了すると、その回の進行はすべて失われます。** 保存機能はまだありません（P6 で作ります）。
「最初から」をやり直したいときは Play を止めて、もう一度 Play してください。

## 6. 見てほしいところ（人による受入。仕様書 §16.2）

5〜10 分で一周してみて、次の 6 点に違和感がないかを教えてください。
**正式スプライトの作画、完成マップの美術、最終的なカメラサイズ、最終的な戦闘バランスは今回の対象外**です。

1. 壁・水・通路・門が見分けられ、歩ける場所が分かるか。
2. Interact の候補が狙った対象になり、調査・レバー・扉の操作が分かるか。
3. 犬丸が曲がり角や門で長く引っ掛からないか。ワープが不自然に頻発しないか。
4. Scene 移動の到着位置・暗転・カメラの境界に違和感がないか。
5. 遭遇戦の開始 → 終了 → 探索復帰が分かりやすいか。動けないまま残らないか。
6. 徳・開通・調査済みが、往復しても死んでも残ることが画面から分かるか。
